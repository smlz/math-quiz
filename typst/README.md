# Quiz Examples and Template

Use the file [`quiz.typ`](./quiz.typ) to author your quiz in your favorite editor.

## Examples

* [`example-quiz.typ`](https://quiz.smlz.ch/create?src=gh:smlz/math-quiz/typst/example-quiz.typ): the default example quiz, when loading the app without a quiz file. It demonstrates all question types and features.
* [`quiz-mengenoperationen.typ`](https://quiz.smlz.ch/create?src=gh:smlz/math-quiz/typst/quiz-mengenoperationen.typ): set operations.
* [`quiz-bilder.typ`](https://quiz.smlz.ch/create?src=gh:smlz/math-quiz/typst/quiz-bilder.typ): geometry questions with images from the [`bilder/`](./bilder) folder, in prompts and as answer options. Images only work when the quiz is loaded from a link, since they are fetched relative to the quiz file.
